## 方法

**MainNet 状态根逐块差分**：
1. 下载 MainNet 区块（渐进式：1K → 10K → 100K → 当前链高）

4. 逐块比对，发现分歧立即停止并调试

## 分歧调试流程

当发现状态根不一致时：

1. **二分定位**：找到第一个分歧块
2. **提取交易**：提取该块的所有交易
3. **逐交易重放**：记录每笔交易后的状态变化
4. **比对差异**：Rust vs C# 的状态变化
5. **定位原因**：找到具体的存储 key/value 不一致
6. **修复代码**：修复 Rust 实现
7. **重新验证**：从分歧点重新运行
