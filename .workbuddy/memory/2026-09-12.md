## 本地 RPC 限流溯源（rpc-probe，读源码，2026-09-12）

- neo-rs RPC 有 **per-IP GCRA 限流器**（governor crate），在 `process_object` 里**每个 JSON-RPC 子请求扣一次**（`neo-rpc/src/server/routes/handlers.rs:253-258`）。**loopback 无豁免**。超限返回 **HTTP 200** 但 body 是 `{"code":-32001,"message":"Too many requests"}` → 客户端必须解析 body 而非 HTTP 状态码。
- 分档（`neo-rpc/src/server/middleware/rate_limiter.rs`，base = MaxRequestsPerSecond）：
  - Cheap 200 rps/burst 400：getblockcount、getversion、getconnectioncount、getrawmempool、getcommittee、getvalidators、ping
  - **Standard 100 rps/burst 200：getstateroot、getblock、gettransaction、其余全部**
  - Expensive 20 rps/burst 40：invokefunction、invokescript、findstorage、findstates、calculatenetworkfee 等
  - Write 10 rps/burst 20：sendrawtransaction、submitblock
- 默认值 `max_requests_per_second=100`、`rate_limit_burst=200`（`rpc_server_settings.rs:169/173`）；`data/Plugins/RpcServer/RpcServer.json`（magic 860833102, port 10332）**两者都没设**→ 走默认。同文件还有 `max_concurrent_connections = 40`。p=80 时约 400 req/s 打 100 rps 额度 → 43% 被限，正如实测。
- **修法（配置，非代码）**：`data/Plugins/RpcServer/RpcServer.json` 的 `Servers[0]` 加 `"max_requests_per_second": 0` 与 `"rate_limit_burst": 0`（0 = 关限流；bind 是 127.0.0.1 所以安全），并把 `max_concurrent_connections` 提高（如 256）。**TOML `[rpc]` 表达不了**——`neo-config/src/settings.rs:89-119` 的 RpcSettings 无任何限流字段，限流配置只存在于插件 JSON。
- **对战役的影响**：限流开启时本地腿硬顶 ~100 hps（加 worker 只会加剧限流）→ 全量 13.14M 高度约 **36.5h**，本地成瓶颈、不可行；关闭后本地腿 loopback 快，瓶颈回到参考侧（~1000 hps → 全量 ~3.6h、stride 2 ~2h）。**任何大规模本地扫描前必须先关限流**，且 verifier `--parallel` 不得超过本地连接上限。
- 注意：`data/Plugins/` 是**全局共享**目录（同 B4），`RpcServer.json` 与 StateService 一样不随数据集隔离 —— 需确认节点启动时是否**覆盖重写**该 JSON（若是，则配置改动不持久，需要代码侧支持）。

- **块 5107 根因（决定性）**：在 root 5107 上逐合约比对 C# vs Rust——
  - `CommitteeInfo`（contract id=1）：**C# 1 条记录（key `0x77+96949ed4…` → 值 `0x400a28…`），Rust 0 条**；
  - GAS（32 条）、NeoToken、Policy、ContractManagement 全部 **C# == Rust**。
  - → **Rust 计算 trie 时没有把 `setInfo` 这次写入算进去**；它的 4 个 put 全部不含 `0x77` 候选键，而这个缺失直接把 root 掀翻。
- **21373 与 5107 无关**（bisect 证据）：21373 的 sender `0xed369077…` 首次获得 GAS 是在**高度 21288**（由跨链 Unlock、经 0x385501cb…/0x5ba6c543… 桥合约入账 3.45 GAS）；在 5107 时它两边的 GAS 都是不存在，且 5107 处 GAS 存储 C# == Rust。→ 两个独立缺陷；21373 属同类缺陷（原生/用户合约写入未反映）但账号/合约不同。
