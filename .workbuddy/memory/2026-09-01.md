## 关键结论（回源 C# 确认，勿再怀疑）
- **`MaxTransactionsPerBlock` 不是收块拒收规则**：C# `Block.Verify` 完全委托 `Header.Verify`；`Blockchain.cs` 全文 0 次引用该常量。它只用于出块（mempool 选交易）与 PrepareRequest 校验 —— Rust 侧用法正确
- **merkle root 校验发生在反序列化期**：C# `Block.DeserializeTransactions` 用 `ushort.MaxValue`(65535) 作 tx 数上限（`BLOCK_MAX_TX_WIRE_LIMIT` 正确），并在此校验 merkle root + 去重。主网 #4554680 确有 512 笔交易仍合法
- C# `ProtocolSettings.EnsureOmmitedHardforks`：未声明者一律填 **0**，遇到首个已配置即 `break`（只补前导空隙）
- C# Oracle 常量：MaxUrlLength=256, MaxFilterLength=128, MaxCallbackLength=32, **MaxUserDataLength=512**, `MinGasForResponse=0_10000000`；存储前缀 Price=5/IdList=6/Request=7/RequestId=9；初始价 50_000_000；每 URL 上限 256 —— Rust 除 user_data 外全对
- C# `RpcError` 权威表（`-506` **不存在**；`Insufficient funds for fee` 是 **-511**；`-100` 不存在，实际 -101~-109；`-509` 被 C# 重复使用两次：InvalidScript 与 InvalidSize）
