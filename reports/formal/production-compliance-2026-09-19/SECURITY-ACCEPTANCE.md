# Neo-rs 安全验收标准

> **日期**：2026-09-19
> **协议基线**：Neo N3 v3.10.1
> **文档定位**：把 Mimosa 门禁要求、凭据约束、以及**尚未满足项**纳入统一的验收标准，用于部署授权前的安全放行判断。
> **诚实声明**：本验收标准区分三类状态——**已满足**（有证据）、**要求强制**（必须执行的口径）、**未满足/待清理**（如实列出，不假装全绿）。

---

## 1. 验收框架

安全验收 = **Mimosa 门禁（可复核密封扫描）+ 凭据约束（强制口径）+ 仓库基线清理（如实列为待办，不与形式验证混淆）+ 协议语义验证证据（G1-G4/G5）**。

任何单项不可替代其余。**安全扫描通过 ≠ 协议语义验证通过**，二者针对不同风险面，必须分开验收。

---

## 2. Mimosa 门禁要求

Mimosa 深度安全扫描产生**密封（sealed）可复核产物**（`scan-manifest.json` / `seal.json` / `report.md`），验收时以封印标识与覆盖状态为准。

### 2.1 验收标准（Mimosa）

- [ ] 提供最近一次深度扫描的**封印标识（seal）**与 `scanId`，且可复核（非运行时声明）。
- [ ] 扫描**覆盖状态**明确；若覆盖缺口存在（如调用图不完整），如实登记并说明对验收结论的影响。
- [ ] 已识别的高/中危 static/cross-file 发现**逐项**有：分类（真实可利用 vs 静态误报待人工确认）、责任人、整改或豁免理由、时限。
- [ ] 关键发现集中在**历史脚本 / `tools` / `external`** 等非运行时路径的，归入"仓库基线清理"（见 §4），**与**协议语义验证**分别**跟踪。

### 2.2 现状（如实）

- Mimosa 扫描历史中，近期深度扫描为 **inconclusive**（覆盖缺口：调用图部分不完整），发现集中在：
  - `tools/scrape_native_contracts.py`、`tools/scrape_syscalls.py`：**SSRF**（动态 URL 未做协议/目标/IP 边界校验）+ **弱加密**（MD5 用于完整性）。
  - `scripts/ci/*` 与 `external/`：**命令注入**、**硬编码凭据**、path-traversal 污点。
  - 均主要落在 **验证/抓取工具与外部引用仓库**，**不属于 `neo-node` 运行时数据路径**；但仍是仓库基线风险，须按 §4 清理。

---

## 3. 凭据约束（强制验收项，不可豁免）

- [ ] **绝不硬编码可用密钥**：所有可用密钥只从**环境变量**或**密钥服务**读取（详见 `COMPLIANCE.md` §1）。
- [ ] 仓库扫描（grep + Mimosa）确认源码/配置/文档/示例中无**可用**密钥（测试夹具可含公开测试向量私钥，但须注明"仅测试"且不对应真实资产）。
- [ ] 容器镜像层不含密钥；CI 日志 secret masking 生效。
- [ ] 共识私钥、RPC 认证、TLS 密码、TEE sealing key 均按受控来源注入。

---

## 4. 未满足项 / 仓库基线待清理（如实提及，不与形式验证混淆）

> **必须读**：以下为**仓库/工具链安全基线的待清理项**，与本次形式验证（G1-G4/G5）是**两个独立问题**。它们的清理进度**不改变**"协议语义是否已验证"的结论，反之亦然。

### 4.1 历史脚本 / 工具高危项（仓库基线）
- [ ] 据 Mimosa 深度扫描历史与静态检索，**仓库内含数量级达几十到上百的历史脚本/工具高危项**（SSRF、命令注入、硬编码凭据、path-traversal、弱加密），主要位于 `scripts/`、`tools/`、`external/`、`docs/` 内嵌脚本与 `target/doc` 生成物。
- [ ] **处置口径**：归为**仓库基线待清理项**，不进生产运行时；但必须在授权上线前**逐个分级**：高=必须修复或从运行环境移除；中=限期整改；纯误报=登记豁免理由。
- [ ] **不混淆声明**：以上高危项是**代码安全扫描**问题，**不是**协议语义/状态一致性问题。形式验证（VM/wire/syscall/Coq）负责协议语义，Mimosa/静态扫描负责代码与供应链安全——两者分开验收、分开汇报。

### 4.2 协议语义未验证项（作为安全验收的"功能安全"维度）
- [ ] 存储/原生合约正路径、完整区块状态一致、Coq 9 个未通过模型等（`DEPLOYMENT.md` §3）**未满足**，列为安全验收的**阻断项**（对阶段 B/C 而言），并如实登记，不以任何扫描/测试通过替代。
