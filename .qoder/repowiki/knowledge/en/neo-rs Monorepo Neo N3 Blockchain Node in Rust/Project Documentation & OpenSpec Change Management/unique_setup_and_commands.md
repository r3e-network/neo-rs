Change proposals follow the openspec convention: create a `openspec/changes/<YYYY-MM-DD>-<slug>/` directory containing `.openspec.yaml`, `proposal.md`, `design.md`, `tasks.md`, and one or more `specs/<topic>/spec.md` files; completed changes are moved into `openspec/changes/archive/`. Protocol consistency runs produce timestamped JSON diffs under `docs/protocol-consistency/reports/compare-goldens-<block>-<timestamp>.json`.
