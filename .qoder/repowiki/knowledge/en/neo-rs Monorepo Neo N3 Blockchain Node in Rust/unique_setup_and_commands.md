Build the full node with `cargo build --release --features full` (required because shipped *.toml configs select RocksDB by default); run a node via `./target/release/neo-node --config neo_<network>_node.toml [--check-config | --rpc-hardened | --tee]`; validate protocol parity through the workspace test command `cargo test --workspace --lib --locked --no-fail-fast` with `neo-core --features runtime` and `neo-rpc --features server`.
