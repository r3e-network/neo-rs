`scripts/mainnet-full-validation.sh [all|<step>] [--no-start-node]` runs the full MainNet import+verify campaign; environment variables `NEO_NODE_BIN`, `REFERENCE_URL`, `VERIFY_START/END`, `CAMPAIGN_START/END`, `EXPECTED_STOPS` control it. `scripts/profiling/benchmark.sh` invokes `cargo bench --bench block_processing -- --profile-time=5` to produce Criterion flamegraphs under `target/criterion`. `tools/sgx-evidence-helper` requires real SGX hardware (`/dev/sgx_enclave`, `/dev/sgx_provision`) and builds via `make` (optional `SGX_SDK=` override), then runs `./sgx_evidence_helper <out-dir>` to emit `sgx.quote` and `sgx.sealing_key` consumed by `neo-node --tee --tee-data-path ...`. `tools/csharp-vm-runner` is run as `dotnet run --project tools/csharp-vm-runner -- <in.json> <out.json>`.
