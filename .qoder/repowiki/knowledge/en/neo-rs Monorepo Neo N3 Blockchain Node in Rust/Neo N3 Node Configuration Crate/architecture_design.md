Single-crate library (`neo-config`) organized into five sibling modules re-exported from `lib.rs`: `settings.rs` defines the top-level `Settings` struct that composes `NodeSettings`, `NetworkConfig`, `ProtocolSettings`, `GenesisConfig`, `StorageSettings`, `RpcSettings`, `ConsensusSettings`, `LoggingSettings`, and `TelemetrySettings`; `network.rs` provides the `NetworkType` enum (MainNet/TestNet/Private) with per-network seed nodes, magic numbers, and address versions; `protocol.rs` hardcodes Neo N3 consensus parameters (validators, block time, native contract activation heights, hardfork heights) via `mainnet()`, `testnet()`, and `private()` constructors; `genesis.rs` supplies mainnet/testnet/private genesis blocks including validator sets, committee lists, and token distributions; `error.rs` centralizes errors as a `thiserror`-derived `ConfigError` enum with a `ConfigResult<T>` alias. Dependency direction is one-way: `settings` depends on `network`, `protocol`, and `genesis`; other modules are independent leaf modules. All structs derive `serde::{Serialize, Deserialize}` and use `#[serde(default)]` with local default-value functions to support partial TOML deserialization, and validation is performed via explicit `validate()` methods called after parsing.
