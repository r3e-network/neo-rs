Build-time proto generation for NeoFS gRPC requires `tonic-build` and `protoc-bin-vendored` in `[build-dependencies]`; enabling the `neofs-grpc` feature triggers `build.rs` to compile `.proto` files under `proto/neofs/`. Many examples require the `rocksdb` feature (declared via `required-features` in `Cargo.toml`). Benchmarks are configured via `[[bench]]` entries for `serialization` and `storage`.
