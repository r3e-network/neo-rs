A standalone Cargo workspace (`neo-rs-fuzz`) declared in `fuzz/Cargo.toml` with `cargo-fuzz = true` metadata, publishing disabled and three `[[bin]]` entries each pointing to a file under `fuzz/fuzz_targets/`. Each target is a `#![no_main]` binary that invokes `libfuzzer_sys::fuzz_target!` and feeds arbitrary `&[u8]` input into one deserialization or validation entry point of the sibling crates: `neo_core::network::p2p::payloads::transaction::Transaction`, `neo_core::script_validation::validate_script`, and `neo_core::network::p2p::message::Message`. Dependencies are local path crates (`neo-core`, `neo-io`, `neo-primitives`, `neo-p2p`); there is no shared fuzz harness — every target is self-contained. The build profile sets `opt-level = 3` with `lto = thin` and debug symbols for release fuzz runs, while dev uses `opt-level = 1`.
