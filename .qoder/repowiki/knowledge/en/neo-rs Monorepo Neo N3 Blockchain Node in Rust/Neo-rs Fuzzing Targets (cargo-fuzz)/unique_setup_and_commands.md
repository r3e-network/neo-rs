Requires Rust nightly plus `cargo install cargo-fuzz` and an LLVM/Clang toolchain. Targets are run as `cd fuzz && cargo fuzz run <target>` (e.g. `fuzz_transaction_parse`, `fuzz_script_parse`, `fuzz_message_parse`), optionally with `-release`, `-workers=N`, `-max_len=...`, `-rss_limit_mb=...`, or seeded via `-seed=`. Crash artifacts land in `fuzz/artifacts/<target>/` and can be reproduced by passing the artifact path back to `cargo fuzz run`. Minimization uses `cargo fuzz tmin`.
