The crate is organized around a core read/write pair: `MemoryReader` (borrowed `&[u8]` buffer with position tracking) and `BinaryWriter` (owned `Vec<u8>` buffer), both exposing typed methods that mirror the C# `Neo.IO.MemoryReader`/`BinaryWriter` API. A central `Serializable` trait (`serializable/mod.rs`) defines `deserialize`, `serialize`, and `size`, and the `impl_serializable!` macro generates implementations for structs containing primitives, nested `Serializable` fields, and variable-length collections (`var_bytes`, `var_string`, `var_array<T>`). Extension traits in `extensions/` add higher-level helpers on top of these core types. The `caching/` subcrate provides a generic `Cache` facade backed by different strategies — `LRUCache`, `FIFOCache`, `HashSetCache`, plus domain-specific caches (`ECPointCache`, `ECDsaCache`, `RelayCache`) — all wrapped with `parking_lot::Mutex`-protected entries and exposed via a shared `impl_cache_facade!` macro. `witness_rule/` models Neo N3 witness conditions/rules as an enum with validation bounds (max depth 3, max subitems 16) and delegates display/JSON/serialization to sibling modules. `compression/` wraps `lz4_flex` behind `compress_lz4`/`decompress_lz4` with configurable thresholds. Dependency direction is one-way: this crate depends only on `neo-primitives` (Layer 0) and standard crates; it does not depend on any other `neo-*` crate.
