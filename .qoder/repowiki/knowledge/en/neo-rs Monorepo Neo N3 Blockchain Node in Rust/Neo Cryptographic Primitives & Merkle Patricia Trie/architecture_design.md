Single Rust crate (`neo-crypto`) exposing a flat public API via `src/lib.rs`, which re-exports the main types from each sub-module. Internal layering is by cryptographic domain: `hash.rs` (SHA-256/512, SHA3, Keccak-256, RIPEMD-160, Blake2b/s, constant-time comparison helpers), `signature.rs` (curve-specific structs `Secp256k1Crypto`, `Secp256r1Crypto`, `Ed25519Crypto`, plus unified `ECDsa`/`ECC` dispatchers), `mpt_trie/` (a self-contained Merkle Patricia Trie with `node`, `node_type`, `cache`, `trie`, `error` sub-modules mirroring the C# `Neo.Cryptography.MPTTrie`), and supporting modules `bip32`, `bloom_filter`, `merkle_tree`, `murmur`, `named_curve_hash`, `encoding`, `crypto_utils`, `error`. Dependency direction is one-way: all sub-modules depend on `error::{CryptoError, CryptoResult}` and on each other only through the `lib.rs` re-exports; there are no cross-cutting frameworks — the crate composes well-known crates (`sha2`, `sha3`, `ripemd`, `blake2`, `blst`, `secp256k1`, `p256`, `ed25519-dalek`, `rand::OsRng`, `subtle`, `zeroize`). Benchmarks live in `benches/crypto_ops.rs` using Criterion, and property-based tests in `tests/property_tests.rs` use proptest.
